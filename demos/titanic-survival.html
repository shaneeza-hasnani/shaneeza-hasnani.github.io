Feature preprocessing

Drops passenger ID, name, ticket and cabin. Missing ages are mean-imputed, missing ports use Southampton, and categorical features are encoded numerically. The browser model uses the same seven input features as the original project, with feature standardization for stable optimization.

About the results

This demo fits a new logistic regression model from the original CSV in JavaScript. It does not pretend to use an exported scikit-learn model: the original repository does not include a saved model artifact.

The browser uses a deterministic 80/20 split and gradient descent. Its accuracy can differ from the Python project, which uses scikit-learn and random_state=2.

Predictions describe patterns in a historical dataset, not what would certainly have happened to an individual passenger.
